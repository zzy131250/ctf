# verify you are human — WRITEUP

**Flag: `K17{ABABBABAABBBAAAA}`**

## 题面

两张手机被没收，照片元数据被抹掉。给 10 张 reference（相机 A、B 各 5 张已知来源）+ 16 张 query，
要求判断每张 query 出自哪台相机，按文件名顺序拼成 flag。`README.txt` 里给了格式：
`img_00`→A、`img_01`→B 时 flag 以 `K17{AB...}` 开头。

## 思路：PRNU 相机指纹

所有照片拍的是同一张猫的线稿（只是裁剪/缩放/旋转不同），所以**画面内容本身不区分相机**，
真正的区分点是传感器固定模式噪声（PRNU）。

关键在于残差提取。第一次用 `img - median3(img)` / `img - boxblur5(img)` 直接做：

- 残差里残留大量**线稿边缘**能量，不同照片的边缘又在同一位置附近，
- 于是任何两张图的残差都相关 ~0.010（同相机、跨相机一样），
- leave-one-out 自检 10 张参考图**错 6 张** —— 说明这个残差根本没抓住 PRNU。

改用 **Mihcak 式小波去噪**（`db8`、4 层），残差 `r = img - denoise(img)`：

1. 每个细节子带用 `σ_n = median(|c|)/0.6745` 稳健估计噪声强度；
2. 3×3 窗口算局部能量 `σ_loc²`，做维纳收缩 `c * max(0, 1 - σ_n²/σ_loc²)`；
3. 重构回去，相减得到残差（只剩传感器噪声，边缘被压掉）。

指纹 `K_cam = mean(该相机 5 张参考图的归一化残差)`，query 用归一化互相关打分。

## 验证

leave-one-out（每次用另外 4 张 A + 5 张 B 建指纹，给被留出的那张打分）：

```
A ref_000..004  delta = +0.0149 +0.0219 +0.0228 +0.0245 +0.0233   全部正确
B ref_000..004  delta = -0.0205 -0.0168 -0.0224 -0.0208 -0.0209   全部正确
LOO accuracy: 10/10
```

query 端同样干脆，16 张的 `|A-B|` 都在 0.024–0.036，没有一张是模棱两可的：

```

img_01 A=+0.0202 B=+0.0456 -> B     img_09 A=+0.0219 B=+0.0470 -> B
img_02 A=+0.0451 B=+0.0177 -> A     img_10 A=+0.0200 B=+0.0491 -> B
img_03 A=+0.0205 B=+0.0445 -> B     img_11 A=+0.0212 B=+0.0449 -> B
img_04 A=+0.0183 B=+0.0426 -> B     img_12 A=+0.0478 B=+0.0225 -> A
img_05 A=+0.0441 B=+0.0185 -> A     img_13 A=+0.0510 B=+0.0202 -> A
```

答案 `ABABBABAABBBAAAA`。

> 注意：用 box/median 残差的那版会给出 `ABABBAAAABBBAAAA`（第 8 位不同），
> 因为那一版基本在噪声里选大小。**PRNU 这类题必须先做 leave-one-out 自检**，
> 自检不过就说明残差提取方式不对，别去信 query 的结果。

## 复现

脚本：`solve.py`（最终分类）、`prnu2.py`（LOO 自检）、
`align2.py`（验证过：对齐后噪声也不相关，排除了"图案随场景变换"的可能）。

依赖：`numpy`、`Pillow`、`pip3 install --user PyWavelets`。
